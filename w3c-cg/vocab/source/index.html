vocab/source

Column 2 of the Canonical Claim Form

The source column answers: who makes this claim?

Specification

PropertyValue
TypeURI (HTTP URI or URN)
RequiredYes
Controlled byEach system provides its own source URI

Usage

The source identifies which system or agent produced the claim. This is the column that makes rotation meaningful: without knowing who asserted a value, you cannot determine which reference frame produced it.

Each system brings its own identity. The protocol does not assign identities. A system's source URI can be any dereferenceable URI or a UUID URN. It must be consistent across all claims from that system.

Examples

SystemSource value

A trading deskhttps://company.com/systems/sgx-desk

Informational irreducibility

Without the source column, frame identity is lost. You cannot determine which side of the boundary produced a claim, and inward/outward rotation collapses.

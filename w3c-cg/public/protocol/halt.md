# protocol/halt

**Boundary undecidable**

- **Key:** `https://w3c-cg.github.io/context-graph/protocol/halt`
- **Value:** Description of the missing context that prevents evaluation

The Halt action fires when Context has not been sufficiently surfaced. No comparison on Meaning, Structure, or Data is valid. The boundary requires resolution before any downstream computation is licensed.

Halt does not mean failure. It means: "we now know this boundary cannot be evaluated without further information." A Halt claim increases the denominator's accuracy (we know the boundary exists) without increasing |E| (no facet has been measured).

Part of the [Context Graph Protocol](https://w3c-cg.github.io/context-graph/).

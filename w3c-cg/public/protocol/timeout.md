# protocol/timeout

**Connection timeout**

- **Key:** `https://w3c-cg.github.io/context-graph/protocol/timeout`
- **Value:** Number of retries attempted, final timeout duration

Recorded after all SYN retries fail. The boundary is marked as CLOSED (unmeasurable). The timeout claim enters the graph: an unmeasurable boundary is not an invisible one. C does not increase, but the denominator is refined.
